## Featured Open-Source Projects

### 1. [Galaxy Buds3 Pro - Ubuntu & Android Seamless Switcher](https://github.com/pulkitmundra/galaxy-buds-ubuntu)
Native **GNOME Quick Settings** extension and CLI tool for **Samsung Galaxy Buds3 Pro** on Ubuntu 24.04+ (GNOME 45-48).
- Solves BlueZ dual-mode (`BR/EDR` vs `LE Audio`) profile negotiation by explicitly binding `A2DP Sink`, `AVRCP`, and `HFP` over D-Bus and routing PipeWire (`wpctl`) audio automatically.
- Instant bidirectional handoff between Ubuntu and Android via MacroDroid webhooks + integrated **GalaxyBudsClient** launcher.

### 2. [Crunchyroll Ubuntu Desktop (Mouse, Trackpad & Smart Auto-PiP Edition)](https://github.com/pulkitmundra/crunchyroll-ubuntu-desktop)
Enhanced Linux desktop and HTPC client for Crunchyroll built on Castlabs Electron (Widevine DRM).
- **Smart Auto-PiP Mini-Player (`F9` / `F10`)**: Automatically shrinks into a pinned `560x315` floating window when switching apps (`Alt + Tab`) and restores to full size in one step when returning.
- **Full Desktop Ergonomics**: Synchronized cursor/HUD auto-hide, click-and-drag timeline scrubbing, smooth trackpad/wheel scrolling across virtualized lists, hover-to-open sidebar, and live debounced search.
